# erp-costing

组件 `erp/costing`（存货成本：按计价序号计算移动平均与先进先出、成本层与暂估、调整、出库成本、成本事实）的仓库。按终局设计从零开始（D59），版本从 `3.0.0` 起（A110）。

设计依据：装配项目 [be-assembly-standard](https://github.com/brickKit/be-assembly-standard) 的边界卡 `docs/zh/07-components/erp-finance.md`（`erp/costing` 一节）、协议 `docs/zh/06-protocols/05b-inventory-costing.md`、决定 D45、D46、D50 与业务流程 `docs/zh/08-flows/procure-to-pay.md`、`docs/zh/08-flows/order-to-cash.md`。代码随重建逐步加入。
